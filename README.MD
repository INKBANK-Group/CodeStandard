# 代码规范

> **本仓库即团队的贡献与代码规范文档（CONTRIBUTING）仓库。**
> 规范正文以 [`CONTRIBUTING.MD`](CONTRIBUTING.MD) 为**唯一事实来源**，本文件仅作入口声明，
> 不再重复正文内容。新增或修改规范请只编辑 `CONTRIBUTING.MD`。

## 内容概览

| 章节 | 说明 |
| --- | --- |
| 项目结构 | 统一目录布局，新项目照此初始化 |
| 代码编写规范 | PEP 8、类型注解、错误处理、日志、配置、依赖管理 |
| 版本控制 | 提交信息格式、分支命名、PR 流程、合并前自检清单 |
| 模板文件 | `.gitignore`、`pyproject.toml`、`LICENSE` 及源码文件头 |

## 快速开始

新项目初始化时，按 [`CONTRIBUTING.MD`](CONTRIBUTING.MD) 的目录结构与模板章节，
复制 `.gitignore`、`pyproject.toml`、`LICENSE` 三个文件至项目根目录，
并在 `pyproject.toml` 中把 `your_package` 替换为实际包名。
